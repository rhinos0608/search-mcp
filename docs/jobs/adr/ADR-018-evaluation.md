# ADR-018: Reproducible evaluation

**Status:** Approved

## Decision

Freeze generic, Sydney/NSW, personalized, identity/lifecycle, extraction, security, source-replay, and pairwise suites. Add graded and pairwise labels, fixed-budget recall, and reproducibility manifests covering git/schema/policy/ranking/pack/adapter/fixture/model/runtime revisions.

## Consequences and verification

Split by identity cluster/time and prevent leakage. Evaluate utility as utility, never as eligibility probability.
